Set up pacer

Takes about three minutes. Nothing changes until you agree.

Add these lines to so you can run pacer in a new terminal.

# >>> pacer >>>
export PATH="$HOME/.local/bin:$PATH"
# <<< pacer <<<

You can remove these changes later from Settings → Uninstall pacer.
