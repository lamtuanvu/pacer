Ink and one accent, used only in the mark and the pace tick, never for status. Status keeps its own green, amber, red and blue, so the brand never reads as "on pace" by accident.
Wordmark pacer Lowercase, system sans, tight tracking. No custom font, so the Orca panel, the CLI help and the status line render it identically with nothing to load.
Where it shows up Panel header and empty states, the plugin's listing icon in Orca's Settings, the installer's output, release pages. Orca's panel tab icon is fixed to its built-in icon set, so that one stays a gauge.
