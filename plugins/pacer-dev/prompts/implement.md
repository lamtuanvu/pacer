# Implement

Implement the approved feature in the run's repository and branch.

- Follow the project's contribution rules (signed commits when committing, Conventional Commits, no real-install changes).
- Keep the change scoped to the brief and approved spec.
- Finish with `pacer step result` summarizing what changed (paths and rationale).

Never touch the person's real pacer install (`/Applications/pacer.app`, `~/.local/bin/pacer*`, `~/.pacer`, `com.pacer.serve`).
