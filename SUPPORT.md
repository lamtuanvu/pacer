# Support

Ask usage and setup questions in [GitHub Discussions](https://github.com/lamtuanvu/pacer/discussions). File reproducible bugs and feature requests in [Issues](https://github.com/lamtuanvu/pacer/issues), using the templates.

Include your pacer version, OS and relevant planner/executor names. Review diagnostic output before sharing it and remove secrets and private paths. Start with the [user docs](docs/README.md) and `pacer doctor`.

These channels will become available when the GitHub repository launches. For vulnerabilities, follow [SECURITY.md](SECURITY.md).
